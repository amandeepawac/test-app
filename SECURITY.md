# Security Policy

## Supported Versions

RozgarLocal is under active development and does not currently publish
versioned releases. Until releases are available, security fixes are made to
the latest commit on the default branch. Older commits and deployment
artifacts are not maintained.

| Version                                | Supported |
| -------------------------------------- | --------- |
| Default branch (latest commit)         | Yes       |
| Other commits and unreleased snapshots | No        |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/amandeep90s/rozgar-local-app/security/advisories/new).
Do not disclose vulnerability details in a public issue or pull request.

Include the affected component and version or commit, the potential impact, and
steps to reproduce the issue. Avoid including real user data, credentials, or
other secrets.

Maintainers aim to acknowledge reports within five business days and provide
status updates at least every ten business days while investigating. These are
targets, not guarantees. If a report is accepted, maintainers will coordinate a
fix and disclosure with the reporter. If it is declined, maintainers will
explain why when possible.

## Dependency Security

Dependency alerts are reviewed and addressed based on severity, reachability,
and available fixes. Security updates are validated with the relevant checks
before they are released.
